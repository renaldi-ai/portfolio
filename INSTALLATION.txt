A. SENDINBLUE (TERMUDAH!) ⭐⭐⭐⭐⭐

Link: https://www.brevo.com

3. Login → Settings → SMTP & API

7. Simpan key ini, Anda akan pakai di Step 3

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

MASALAH: test-email.php menunjukkan error
─────────────────────────────────────────────────────────────────────
SOLUSI:
1. Cek config.php sudah disave dengan benar
2. Cek tidak ada typo di SMTP credentials
3. Cek tidak ada spasi ekstra
4. Re-upload config.php

MASALAH: "SMTP connect() failed"
─────────────────────────────────────────────────────────────────────
SOLUSI:
1. SMTP_HOST, PORT, USER, PASS salah
2. Copy-paste ulang credentials dari provider
3. Untuk Sendinblue: coba port 2525 (ganti 587 → 2525)
4. Hubungi hosting support (mungkin port diblokir)

MASALAH: "Could not authenticate"
─────────────────────────────────────────────────────────────────────
SOLUSI:
1. SMTP_USER atau SMTP_PASS salah
2. Untuk Sendinblue: pastikan pakai SMTP KEY bukan password login
3. Buat SMTP key baru
4. Copy dengan benar (no extra spaces/enters)

MASALAH: Email tidak masuk
─────────────────────────────────────────────────────────────────────
SOLUSI:
1. Cek folder SPAM
2. Wait 1-2 menit
3. Cek dashboard provider (email sent?)
4. Data tetap tersimpan di contact_submissions.json
