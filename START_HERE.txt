⚡ QUICK START (Tidak Mau Baca Banyak?)
═══════════════════════════════════════════════════════════════════════

Ini versi super cepat:

1. Upload semua file ke hosting
2. Daftar di: https://www.brevo.com (gratis)
3. Login → Settings → SMTP & API → Create SMTP key
4. Copy key yang muncul
5. Edit config.php:
   - Isi SMTP_USER dengan email Anda
   - Isi SMTP_PASS dengan key yang di-copy
   - Isi SITE_EMAIL dengan email penerima
6. Save & upload config.php
7. Test: http://yoursite.com/test-email.php
8. Hapus test-email.php
9. Done! ✅

Detail lengkap? Baca INSTALLATION.txt
